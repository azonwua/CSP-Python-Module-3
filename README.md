# CSP-Python-Module-3

This project is a simple library management program written in Python. It allows users to add books, view all the books in the library, and search for a book by its title or author.

Files
book.py - Contains the Book class. Each book has a title, author, and ISBN.
library_manager.py - Contains the main program and menu. It allows the user to add, list, and find books.
Features
Add a new book by entering the title, author, and ISBN.
List all books currently in the library.
Find a book by searching for its title or author.
Exit the program.
Sample Book

The program includes a sample book:

Title: Harry Potter and the Sorcerer's Stone
Author: J.K. Rowling
ISBN: 9780439708180
How to Run

Make sure both book.py and library_manager.py are in the same folder.
